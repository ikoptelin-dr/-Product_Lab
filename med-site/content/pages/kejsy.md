# Кейсы: маркетинг, который не заканчивается на визите

Каждый кейс — по схеме STAR: ситуация, задача, действия, результат. Плюс метод, чтобы было видно ход мысли. ==Цифры помечены: факт проекта или ориентир по рынку.==

2. [Проект для мам: о чём тревожатся пациенты](/kejsy/proekt-dlya-mam/)

Общее у всех пяти: мы отвечаем за то, что происходит с человеком после первого контакта.

## Как читать цифры

- **Факт проекта** — объём выполненной работы, проверяемый по файлам.
- **Ориентир по рынку** — среднерыночное значение для такого типа проекта. Заменяем фактами клиента, как только он их передаёт.
- Клиентов называем только с их разрешения.
