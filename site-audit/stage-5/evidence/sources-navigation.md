# Источники, использованные для навигации по нормативным утверждениям (28.10.2026)

Первичные официальные источники (publication.pravo.gov.ru, eec.eaeunion.org, docs.eaeunion.org, pub.fsa.gov.ru, consultant.ru) из этой сессии **недоступны**: сетевая политика среды отклоняет соединения (curl: CONNECT 403; WebFetch: ENOTFOUND). Доступен только веб-поиск, который возвращает заголовки и пересказ вторичных публикаций. Поэтому ни одно нормативное утверждение не получило статус «подтверждено»: максимум — «вторичные совпадают, требуется профильная проверка».
