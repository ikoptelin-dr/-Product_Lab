## Выбор

1. **Playwright — да, тот, что уже стоит (1.56.0).** На нём построен `verify.mjs`. Браузерные сценарии, DOM, скриншоты на 1440/768/390 и визуальные сравнения (`toHaveScreenshot` или сравнение файлов) закрываются без установки. Последняя версия в npm — 1.64.1; обновление не требуется, и на этом этапе его не делаем.
2. **axe-core — да.** Пакет уже лежит в `node_modules`. Встраивается без установки: `page.addScriptTag({ path: '.../axe-core/axe.min.js' })`, затем `page.evaluate(() => axe.run())`.
   - Обёртка `@axe-core/playwright` 4.14.0 удобнее, но требует Node ≥ 22.12 (есть 22.22) и установки пакета. Без неё можно обойтись.
   - Ограничение: axe находит не больше трети–половины проблем доступности. Ручные проверки (фокус, порядок чтения, контраст на градиентах и поверх видео) остаются.
3. **Lighthouse — да, но нужна установка.** В окружении его нет.
   - Последняя версия — 13.6.0, требует Node ≥ 22.19 (у нас 22.22 — совместимо). Для Chromium нужна переменная `CHROME_PATH=/opt/pw-browsers/chromium`.
   - 13.6.0 обновлена 2026-10-27, поэтому разумно закрепить проверенную предыдущую минорную версию.
   - Запуск без глобальной установки: `npx -y lighthouse@<версия> http://127.0.0.1:<порт>/index.html --chrome-flags="--headless=new --no-sandbox" --output=json --output=html --output-path=...`.
   - Lab-данные на локальном `http.server` без gzip и HTTP/2 не равны боевым. Для прод-оценки нужен сервер с конфигом `deploy/nginx.conf`.
4. **Crawlee — нет.** Сайт статический, около 85 HTML-файлов, полный список берётся из `dist/` и sitemap, ссылки уже проверяет сборка. Очереди и повторы не нужны.
5. **Trafilatura — нет.** Основной текст надёжно извлекается из `<main>`: исходники статей — Markdown в репозитории. Кроме того, пакета нет в окружении, а он требует Python-установки.
