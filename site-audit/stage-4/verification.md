## Ограничения

- **nginx не проверялся.** В окружении его нет:
  - HTTP-статус 404 для несуществующих адресов не проверен — проверено только содержимое `404.html`;
  - `client_max_body_size 6m` проверен мини-прокси с тем же пределом;
  - `nginx -t` не запускался.
- **Telegram не настоящий.** Подменён локальным получателем через `TG_API`. Боевой бот, сервер и реальные заявки не использовались.
- **Метод контраста.** Для «incomplete»-узлов элемент снимается со скрытым текстом, цвет текста сравнивается с худшими (5-й процентиль) пикселями фона. Сочетания (цвет текста + класс фона + размер) дедуплицированы: одинаковое сочетание на разных страницах измерено один раз. Редкий фон-картинка, совпавший по сигнатуре, мог быть не измерен отдельно.
- **Контраст интерактивных состояний.** Сообщение об ошибке поля (`#b91c1c` на белом, 6,47:1) рассчитано, а не замерено пикселями.
- **Lighthouse не задевает правила ≤ 374 px.** Мобильный пресет — 412 px. Узкие ширины проверены Playwright, не Lighthouse.
- **Перенос посреди слова при 320 px** («позиционирование» в H1, «Сформулировать» в кнопке) — сознательный компромисс вместо обрезки, ISS-025.
- **Локальная прокрутка таблиц** (`.table-wrap`) допустима и не считается переполнением, ISS-026.
- **Глобальный `overflow-x: hidden`, обрезание текста и уменьшение сайта не использовались.** Эталоны не обновлялись автоматически, критерии проверок не ослаблялись: правило `.prose .sec-title` убрано, потому что ломало слово, а не чтобы пройти проверку.
- **Скриншоты verify (26 МБ) перенесены в scratchpad** как дубль. Скриншоты целых страниц тоже лежат там. В `evidence/` оставлены только образцы отличий (2,5 МБ) и сжатые отчёты Lighthouse.
