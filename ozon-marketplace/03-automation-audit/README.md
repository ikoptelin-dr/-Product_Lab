# Аудит автоматизации

Агент: `.claude/agents/ozon-automation-auditor.md`.
Запускать, когда готовы отчёты в `01-market-research/` и `02-tech-analysis/reports/`.
Запуск в Claude Code: «запусти ozon-automation-auditor». Результат: `report.md` в этой папке.

## Гипотезы, которые аудитор должен подтвердить или опровергнуть

| Точка | Инструмент | Почему важно |
|---|---|---|
| Сверка «Озон ↔ поставщики ↔ банк» | код + агент на расхождения | Из-за этого ушёл бухгалтер партнёра; без неё нельзя расти |
| Сопоставление артикулов и кроссов между поставщиками | код + LLM на спорные случаи | Один товар у разных поставщиков называется по-разному; от этого зависят дубли карточек и выбор поставщика |
| Применимость по маркам и моделям | LLM + проверка по каталогу | Ошибка = возврат и плохой отзыв; в автозапчастях главная причина возвратов |
| Массовая генерация карточек | LLM | 40 000 карточек вручную не сделать |
| Ответы на вопросы «подойдёт ли на мою машину» | агент с доступом к базе применимости | Быстрый ответ повышает конверсию, неверный — даёт возврат |
| Цены, остатки, маршрутизация заказа | обычный код | Нужна скорость и предсказуемость, LLM здесь не нужен |
