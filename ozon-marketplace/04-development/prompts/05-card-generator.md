# 05. Генератор карточек

Когда: после шагов 02 и 04. Нужно решение, какой провайдер LLM используем (см. `ANALYSIS.md`, раздел 4, пункт 5).
Впишите его в промпт.

```text
Шаг 05 проекта ozon-marketplace: генератор карточек. Провайдер LLM: <впиши: YandexGPT / GigaChat / пакетно здесь>.

Прочитай ozon-marketplace/CLAUDE.md, STATUS.md, 04-development/ozon-attributes.md. Справочник — раздел 2.6 отчёта ChatGPT.

1. Для каждой детали пилота собери «паспорт»: только факты из каталога с источником каждого поля (бренд, артикул,
   OEM-ссылки, применимость из проверенного источника, сторона/ось, размеры, комплектность, вес и габариты упаковки, фото).
2. Генерация: LLM получает паспорт и список атрибутов Озона для категории и типа, возвращает JSON: название, описание,
   значения атрибутов. Правило в промпте модели: только факты из паспорта; поля без данных — пустые, не придумывать.
   Применимость упоминать только из паспорта.
3. Валидатор кодом: каждое значение атрибута есть в паспорте или в справочнике Озона; обязательные атрибуты заполнены;
   в тексте нет марок и моделей, которых нет в применимости; длины в пределах ограничений Озона.
   Карточка с ошибками валидации не публикуется.
4. Экран проверки: черновик рядом с паспортом, кнопки «утвердить», «исправить», «отклонить». Первые 20 карточек каждого
   типа утверждает человек; статистика правок.
5. Публикация: /v3/product/import пакетами (размер — из конфига, по умолчанию небольшой), затем /v1/product/import/info
   по каждому товару, ошибки — в очередь, повтор только исправленных. Стабильный offer_id = наш ключ детали.
   Цены и остатки этот модуль не трогает.
6. Публикация в реальный кабинет — только по моей команде `catalog publish --confirm`. По умолчанию — сухой прогон
   (печатает, что отправил бы).
7. Тесты: модель «добавила» несуществующую применимость — валидатор отклоняет; пустое обязательное поле — отклонено;
   повторная публикация без изменений не отправляется.

В конце: STATUS.md, коммит, пуш. Ответь: сколько черновиков, доля прошедших валидацию, типичные ошибки модели,
пример 3 карточек для моей проверки (вставь в ответ).
```
