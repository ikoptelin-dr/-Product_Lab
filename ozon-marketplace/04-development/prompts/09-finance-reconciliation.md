# 09. Финансы и сверка

Когда: после шага 08, лучше — когда есть первый месяц продаж. Нужны образцы УПД поставщика и выписка банка
(положите в `04-development/partner-data/` или отдельную папку вне git). Впишите, в чём ведёт учёт бухгалтер.

```text
Шаг 09 проекта ozon-marketplace: финансы и сверка. Учётная система бухгалтера: <впиши: МойСклад / 1С / не выбрана>.

Прочитай ozon-marketplace/CLAUDE.md и STATUS.md. Справочник — раздел 5 отчёта ChatGPT целиком.

1. Загрузка источников с хешем и версией (повтор не создаёт дубль): отправления, отчёт о реализации (/v2/finance/realization,
   /v1/finance/realization/posting), начисления (/v1/finance/accrual/* — НЕ старые transaction), возвраты, УПД/УКД поставщика
   (XML из ЭДО, при скане — извлечение полей через LLM с проверкой арифметики кодом), выписка банка.
2. Классификатор начислений Озона: реализация, вознаграждение, прямая и обратная логистика, услуги, компенсации,
   корректировки. Неизвестный тип — в очередь разбора, не в «прочее».
3. Сверка по порядку из 5.3 (8 шагов): арифметика документа → связи по ID → бренд+артикул+количество+период →
   многие-ко-многим для частичных отгрузок → баланс расчётов с Озоном → баланс расчётов с поставщиком → товарный баланс →
   очередь исключений.
4. Очередь расхождений (reconciliation_issue): тип, сумма, ответственный, срок. LLM пишет понятное объяснение расхождения
   и предлагает связь, но не проводит её — проводит код по правилам или человек.
5. Выгрузка бухгалтеру: реестр продаж, закупок и возвратов за месяц в формате для её системы (CSV/XLSX; для МойСклад —
   через API, если доступен). Закрытие месяца фиксирует период; поздние изменения — корректировкой.
6. Отчёт о прибыли по месяцам и по товарам: выручка, удержания Озона по типам, закупка, вклад, налоги (по таблице из шага 06).
7. Тесты: возврат прошлого месяца; один УПД на 15 заказов; одна закупка на два отправления; повторная загрузка отчёта
   новой версии; неизвестный тип начисления.

В конце: STATUS.md, коммит, пуш. Ответь: какая доля суммы и строк сопоставлена автоматически, топ-3 причины
расхождений, что нужно от бухгалтера.
```
