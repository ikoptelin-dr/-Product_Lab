# 07. Доступность и синхронизация остатков и цен

Когда: после шагов 03 и 06. Для живой записи в кабинет нужен ключ Озона с правами на запись — **только после того, как
вы прочитали отчёт шага и согласны**.

```text
Шаг 07 проекта ozon-marketplace: доступность, остатки и цены на Озоне.

Прочитай ozon-marketplace/CLAUDE.md и STATUS.md. Справочник — разделы 2.3, 4.4, 4.5 отчёта ChatGPT.

1. Доступность считается по маршруту (поставщик + склад + наш склад Озона):
   остаток = min(лимит экспозиции, max(0, свободный остаток − наши неотражённые резервы − буфер)).
   Пилот: лимит экспозиции 2, буфер по конфигу. Тип остатка «под заказ» или «больше N» — по правилам из конфига,
   по умолчанию «под заказ» = 0.
2. Обнуление по условиям: прайс старше TTL (по поставщику), склад закрыт (календарь), дневная мощность сборки исчерпана,
   цена стала «не продаём», поставщик отключён. Неполный прайс не «омолаживает» каталог.
3. Передача в Озон только изменений: версия и хеш итогового значения; в очередь попадают только изменения.
   Обнуление — очередь stock_zero, высший приоритет; рост остатка — stock_positive; цены — prices.
   Последовательные изменения одного ключа схлопываются, старое задание не может вернуть старое значение.
4. Методы: /v2/products/stocks, /v1/product/import/prices — сверить схему с документацией; результат по каждой позиции
   (HTTP 200 не значит, что всё принято).
5. Аварийный рубильник: команда `stock kill-switch --supplier X` обнуляет все его предложения за минимальное время.
6. Режим сухого прогона по умолчанию; живая запись — флаг конфигурации, который включаю я.
7. Тесты: прайс просрочен → все его позиции уходят в ноль раньше любых цен и каталога; повтор одного и того же значения
   не отправляется; два изменения подряд → отправлено только последнее; частичная ошибка в пакете → повтор только
   ошибочных позиций.
8. Расчёт: при лимитах из STATUS.md (шаги 02, 03) сколько минут занимает полный проход по 100, 1 000, 10 000, 40 000 позиций.

В конце: STATUS.md, коммит, пуш. Ответь: как быстро обнуление доходит до Озона (оценка), что включить для живого режима.
```
