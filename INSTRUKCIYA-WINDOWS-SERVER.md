# Как выложить сайт proba-lab.ru на свой компьютер с Windows

Эта инструкция — для сервера на **Windows 10 или 11**. Linux не нужен, ничего переустанавливать не нужно.

**Что получится:** компьютер под столом показывает сайт https://proba-lab.ru всему интернету. Заявки с сайта приходят вам в Telegram. После выключения света или перезагрузки сайт запускается сам.

**Как это устроено (одной фразой):** Node.js показывает сайт и принимает заявки, а Caddy получает бесплатный замок HTTPS и пропускает посетителей из интернета.

**Что понадобится:**
- флешка;
- компьютер, на котором вы открываете GitHub (можно сам сервер);
- пароль от роутера (обычно на наклейке снизу роутера);
- логин и пароль от сайта, где куплен домен proba-lab.ru (reg.ru, nic.ru, Timeweb, Beget или другой);
- Telegram на телефоне;
- около часа времени.

> Если на любом шаге видите красное `[XX]` или непонятную ошибку — сфотографируйте экран и пришлите. Не пытайтесь «починить» наугад.

## Шаг 0. Узнать, «белый» ли у вас IP (без этого сайт не будет виден)

Компьютер дома можно открыть из интернета, только если провайдер даёт **белый статический IP-адрес**.

1. На сервере откройте в браузере сайт **2ip.ru** и запишите большие цифры, например `85.140.12.34`.
2. Откройте настройки роутера: в браузере наберите `192.168.0.1` или `192.168.1.1` (точный адрес — на наклейке роутера) и войдите.
3. На главной странице роутера найдите «IP-адрес WAN», «Внешний IP» или «Интернет — IP-адрес».
4. Сравните:
   - **цифры совпали** — хорошо, переходите дальше. Всё равно позвоните провайдеру и уточните, что адрес **статический** (не меняется);
   - **цифры разные** или адрес в роутере начинается с `10.`, `100.`, `172.` или `192.168.` — у вас «серый» адрес. Позвоните провайдеру и скажите: **«Подключите мне статический белый IP-адрес»**. Обычно это 100–300 ₽ в месяц. Без этого дальше идти бесполезно.

Запишите белый IP — он понадобится в шаге 9.

## Шаг 1. Скачать пакет с сайтом на флешку

1. Войдите на GitHub под своим аккаунтом.
2. Откройте ссылку:
   **https://github.com/ikoptelin-dr/-Product_Lab/blob/claude/pensive-tesla-1hg10j/PROBA-SERVER.zip**
3. Справа нажмите кнопку со стрелкой вниз (**Download raw file**). Скачается файл `PROBA-SERVER.zip`.
4. Скопируйте `PROBA-SERVER.zip` на флешку.

> Больше с GitHub ничего не нужно. В архиве уже готовый сайт и все файлы для запуска.

---

## Шаг 2. Положить папку proba на диск C:

1. Нажмите на `PROBA-SERVER.zip` правой кнопкой → **«Извлечь все…»** → ничего не меняйте → **«Извлечь»**. Рядом появится папка `PROBA-SERVER`.
2. Откройте её. Внутри — папка **`proba`**. Нажмите на неё правой кнопкой → **«Копировать»**.
3. Откройте **«Этот компьютер» → «Локальный диск (C:)»**. Нажмите правой кнопкой на пустом месте → **«Вставить»**.
   - Windows спросит «Нужно разрешение администратора» — нажмите **«Продолжить»**.
4. Откройте `C:\proba`. **Правильная папка** — та, в которой сразу видны файлы `1-POSMOTRET-SAJT.bat`, `2-VKLYUCHIT-AVTOZAPUSK.bat` и папка `site`.
   - Если внутри ещё одна папка `proba`, а файлы лежат в ней — значит, скопировали на уровень выше. Удалите `C:\proba` и повторите пункт 2 с внутренней папкой.
5. Включите показ расширений файлов, чтобы видеть `.exe` и `.bat`:
   - Windows 11: в окне папки **«Просмотреть» → «Показать» → «Расширения имён файлов»**;
   - Windows 10: вкладка **«Вид»** → галочка **«Расширения имён файлов»**.

> Не можете найти папку, которую извлекали раньше? Неважно, просто сделайте этот шаг заново. Лишние копии на Рабочем столе можно потом удалить.

## Шаг 3. Node.js — один файл node.exe (программа, которая показывает сайт)

**Если вы скачали Node.js zip-архивом** (папка вида `node-v26.13.0-win-x64`):
1. Откройте эту папку. В ней лежит файл **`node.exe`**.
2. **Скопируйте `node.exe` в `C:\proba`**. Устанавливать ничего не нужно.

**Если ещё не скачивали:** на **nodejs.org** скачайте **«Windows Installer (.msi)»** версии LTS и установите (Next → I accept → Next → Install → Finish), затем перезагрузите компьютер. Подойдёт любой из двух способов.

> Если дважды щёлкнуть `node.exe`, откроется чёрное окно с логотипом Node.js и строкой `>`. Это нормально: программа просто ждёт команд. Закройте окно. Запускать его вручную не нужно — это делают наши файлы.

---

## Шаг 4. Caddy — один файл caddy...exe (программа для HTTPS)

1. Откройте **caddyserver.com/download**, в списке **Platform** выберите **Windows amd64** и нажмите **Download**. Скачается файл вроде `caddy_windows_amd64.exe`.
2. **Скопируйте этот файл в `C:\proba`.** Переименовывать не нужно.

> Если дважды щёлкнуть Caddy, на 15 секунд появится окно с надписью «you need to open cmd.exe and run it from there» и закроется. Это нормально: Caddy сам по себе не запускается двойным щелчком. Его запускают наши файлы.

**После шагов 2–4 в `C:\proba` должны лежать:** `node.exe`, `caddy_windows_amd64.exe`, `1-POSMOTRET-SAJT.bat`, `2-VKLYUCHIT-AVTOZAPUSK.bat`, `3-PROVERIT-VSE.bat`, `nastrojki.txt`, папка `site` и другие файлы.

## Шаг 5. Посмотреть сайт на этом компьютере

1. В папке `C:\proba` дважды щёлкните **`1-POSMOTRET-SAJT.bat`**.
2. Если Windows пишет «Windows защитил ваш компьютер», нажмите **«Подробнее» → «Выполнить в любом случае»**.
3. Откроется чёрное окно и браузер с адресом http://localhost:8080. Там должен быть ваш сайт.
4. Посмотрели — закройте чёрное окно. Это была только проверка.

## Шаг 6. Сделать Telegram-бота для заявок

1. В Telegram найдите **@BotFather** (с синей галочкой) и нажмите **Start**.
2. Отправьте ему `/newbot`.
3. Отправьте имя бота, например `Proba Lab заявки`.
4. Отправьте короткое имя на латинице, оканчивающееся на `bot`, например `proba_lab_leads_bot`.
5. BotFather пришлёт **токен**: длинную строку вида `1234567890:AAH…`. Это ключ от бота. Никому его не показывайте.
6. Нажмите на ссылку вашего нового бота, нажмите **Start** и напишите ему любое слово, например «привет».
7. В браузере откройте адрес, вставив вместо `ТОКЕН` свой токен:
   `https://api.telegram.org/botТОКЕН/getUpdates`
8. На странице найдите `"chat":{"id":` и запишите число после него, например `123456789`. Это номер чата.
9. Откройте файл **`C:\proba\nastrojki.txt`**: правой кнопкой → «Открыть с помощью» → **Блокнот**. Впишите значения сразу после `=`, без пробелов:
   ```
   TG_TOKEN=1234567890:AAH...ваш токен...
   TG_CHAT=123456789
   ```
10. Сохраните файл (**Ctrl+S**) и закройте Блокнот.

## Шаг 7. Включить автозапуск

1. Дважды щёлкните **`2-VKLYUCHIT-AVTOZAPUSK.bat`**.
2. Windows спросит «Разрешить этому приложению вносить изменения?» — нажмите **«Да»**.
3. Откроется синее окно. Скрипт сам:
   - откроет порты 80 и 443;
   - запретит компьютеру засыпать;
   - включит автозапуск сайта;
   - всё проверит.
4. Зелёные строки `[OK]` — хорошо. На этом этапе **нормально**, если жёлтым или красным отмечены строки про домен proba-lab.ru: его мы настроим в шаге 9.
5. Найдите строку **«Адрес этого компьютера в домашней сети: 192.168.x.x»** и запишите этот адрес. Он нужен в шаге 8.
6. Нажмите Enter, чтобы закрыть окно.

Теперь сайт работает сам, даже если никто не вошёл в Windows. Чёрных окон не будет: всё идёт в фоне.

## Шаг 8. Настроить роутер (2 действия)

Откройте настройки роутера, как в шаге 0.

**8.1. Закрепить адрес за сервером.** Иначе после перезагрузки роутер может выдать компьютеру другой адрес.
- Найдите раздел **DHCP** → «Резервирование адресов», «Привязка IP к MAC» или «Постоянный IP».
- Выберите в списке свой сервер (адрес из шага 7) и сохраните.

**8.2. Пробросить порты 80 и 443 на сервер.** Раздел называется по-разному:

| Роутер | Где искать |
|---|---|
| Keenetic | «Сетевые правила» → «Переадресация» |
| TP-Link | «NAT переадресация» → «Виртуальные серверы» (или «Дополнительные настройки» → «NAT») |
| ASUS | «Интернет» → «Переадресация портов» |
| Роутер провайдера (Ростелеком, МТС, Билайн, Дом.ру) | «Переадресация портов», «NAT» или «Виртуальный сервер» |

Создайте **два правила**:

| Название | Протокол | Внешний порт | IP-адрес компьютера | Внутренний порт |
|---|---|---|---|---|
| proba-http | TCP | 80 | адрес из шага 7 | 80 |
| proba-https | TCP | 443 | адрес из шага 7 | 443 |

Сохраните.

> **Больше никаких портов не открывайте:** ни 3389 (удалённый рабочий стол), ни другие. Это небезопасно.

## Шаг 9. Направить домен proba-lab.ru на ваш IP

1. Войдите на сайт, где куплен домен (reg.ru, nic.ru, Timeweb, Beget…).
2. Откройте домен proba-lab.ru → **«DNS-записи»**, «Управление DNS» или «Ресурсные записи».
3. **Удалите** старые записи типа **A** и **AAAA** для `@` и для `www`, если они есть (обычно это «парковка» регистратора).
   - **Не трогайте** записи **MX** и **TXT**: от них зависит почта i.koptelin@proba-lab.ru.
4. Добавьте **две записи**:

| Тип | Имя (хост) | Значение |
|---|---|---|
| A | `@` | ваш белый IP из шага 0 |
| A | `www` | ваш белый IP из шага 0 |

5. Сохраните. Изменения расходятся по интернету **от 15 минут до суток**.

> Если регистратор пишет, что домен использует «чужие DNS-серверы», записи нужно менять там, куда эти серверы указывают. Или переключите на DNS-серверы регистратора.

## Шаг 10. Проверить, что всё работает

1. Через 15–30 минут после шага 9 дважды щёлкните **`3-PROVERIT-VSE.bat`** и нажмите «Да».
2. Все строки должны быть зелёными `[OK]`. Самая важная — «proba-lab.ru указывает на этот сервер».
3. **Главная проверка — с телефона.** Выключите на телефоне Wi-Fi, чтобы работал мобильный интернет, и откройте **https://proba-lab.ru**. Должен открыться сайт с замочком.
   - Из домашнего Wi-Fi сайт по имени proba-lab.ru может **не открываться** — это особенность многих роутеров, не ошибка. Проверяйте с мобильного интернета.
4. Заполните на сайте любую форму, например в разделе «Контакты». Через несколько секунд в Telegram должна прийти заявка.

Готово, сайт в интернете.

## Как обновить сайт, когда я пришлю новую версию

1. Скачайте новый `PROBA-SERVER.zip`, как в шаге 1, и распакуйте его на Рабочий стол.
2. Из распакованной папки `proba` скопируйте **только папку `site`** в `C:\proba` и нажмите «Заменить файлы».
3. Перезапускать ничего не нужно: новые страницы видны сразу.

> **Не копируйте поверх `nastrojki.txt`**, иначе сотрёте токен Telegram. Если я напишу, что изменился `server.mjs`, скопируйте ещё `server.mjs` и `form-endpoint.mjs`, затем запустите `OSTANOVIT-SAJT.bat` и `ZAPUSTIT-SAJT.bat`.

## Если что-то не работает

| Что видите | Что делать |
|---|---|
| При запуске `1-POSMOTRET-SAJT.bat`: «node не является внутренней или внешней командой» | В `C:\proba` нет файла `node.exe` — шаг 3 |
| `[XX] Порт 80 занят другой программой` | Чаще всего это встроенный в Windows веб-сервер IIS. «Панель управления» → «Программы» → «Включение или отключение компонентов Windows» → снимите галочку «Службы IIS» → перезагрузка |
| `[XX] В папке нет caddy...exe` | Шаг 4: файл Caddy должен лежать прямо в `C:\proba` |
| Сайт открывается на сервере, но не с телефона | По порядку: белый IP (шаг 0), проброс портов (шаг 8), DNS (шаг 9). Если провайдер закрывает входящие порты 80/443 — позвоните ему и попросите открыть |
| В браузере «Не защищено» или ошибка сертификата | Подождите 10–15 минут после настройки DNS: Caddy получает сертификат сам. Если не помогло — пришлите последние строки из `C:\proba\logs\caddy.log` |
| Заявки не приходят в Telegram | Запустите `3-PROVERIT-VSE.bat` и посмотрите строку про Telegram. Проверьте, что нажали Start в своём боте и что TG_CHAT записан верно. Заявки всё равно сохраняются в `zayavki\zayavki.jsonl` |
| Компьютер перезагрузился или отключали свет | Ничего не делать: сайт запустится сам через 1–2 минуты после включения |
| Нужно выключить сайт | `OSTANOVIT-SAJT.bat`. Включить снова — `ZAPUSTIT-SAJT.bat` |

**Чтобы сервер работал стабильно:**
- не выключайте компьютер;
- поставьте пароль на вход в Windows;
- не отключайте обновления Windows: после перезагрузки сайт поднимется сам;
- раз в месяц копируйте папку `zayavki` на флешку.
