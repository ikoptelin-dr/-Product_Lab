# Блоки вместо текста: как размечать страницы (дизайн-система v4)

Сборка (`proba-site-v3/src/blocks.ts`) сама превращает разметку Markdown в визуальные блоки. Автору не нужен HTML — достаточно правильной формы раздела. Цель: страница читается за 30 секунд по заголовкам, карточкам и выделениям; подробности свёрнуты.

Дополняет `CONTENT-GUIDE.md` и план `../strategy/SITE-REDESIGN-PLAN.md`. Все правила CONTENT-GUIDE (факты, стоп-лист, запрещённые слова) остаются в силе.

## 1. Какая разметка во что превращается

| Разметка в .md | На сайте |
|---|---|
| Каждый `## Раздел` (услуги, хабы, кейсы) | Отдельная полоса; светлые и тонированные чередуются |
| Первый абзац раздела | Крупная вводная. **1–2 предложения** |
| Список `- **Заголовок** — текст` (2–8 пунктов) | Карточки с иконкой. 4 или больше 6 пунктов — сетка в 4 колонки |
| Нумерованный список `1. **Шаг** — текст` | Шкала шагов с номерами 01, 02… |
| Таблица из 2 колонок в разделе «Стоимость» / «Сколько стоит» / «Смета» | Ценовые карточки «от …» |
| Список в разделе «Кому подходит», «Когда нужно», «Для кого», «Что нужно от вас» | Колонка с галочками ✓ |
| Список в разделе «Когда не подходит», «Что не заменяет» | Колонка с крестиками ✕ |
| Список в разделе «Частые ошибки», «Риски» | Карточки-предупреждения |
| Список ссылок `- [Название](/url/) — коротко` или раздел «Что дальше» | Карточки-ссылки |
| `## Коротко` + 3 пункта (статьи блога) | Карточка «Коротко» в начале статьи |
| `==ключевая мысль==` | Маркерное выделение |
| `:::подробнее Заголовок` … `:::` | Свёрнутый блок «Подробнее» |

Иконка карточки выбирается по словам заголовка: документ, проверка, этикетка, 3D, карточка, видео, аналитика, позиционирование, исследование, клиенты, сроки, состав, цена, автоматизация.

## 2. Правила

1. **Заголовок карточки — 1–5 слов, текст — до 20 слов.** Длиннее — значит, это абзац, а не карточка.
2. **Абзац — до 3 строк (≈45 слов).** Длинный абзац разбейте или переведите в список.
3. **Выделение `==…==` — не больше одного на раздел**, 3–8 слов, главная мысль. Не выделяйте метки фактов ⟪…⟫ целиком.
4. **«Подробнее»** — для оговорок, исключений, длинных пояснений, которые нужны для SEO и точности, но не для первого прочтения. Пустая строка до `:::подробнее …` и до закрывающей `:::`. Внутри нельзя ставить формы и CTA (`**[Форма…]**`, `**[CTA…]**`).
5. **Бюджеты** (тело без FAQ и служебной части): главная 250–350 слов, услуга 300–450, хаб 150–250, кейс 400–600. Статьи блога не сокращаем — только разбиваем стену текста.
6. **Не трогать:** frontmatter (title, description, h1, url), фразы из Wordstat в первом абзаце и подзаголовках, вопросы FAQ, цены, строки форм и CTA, ссылки, текст меток ⟪ключ|фраза⟫ — дословно. Факты можно переносить между разделами и в «Подробнее» вместе с меткой.
7. **Ничего не выдумывать.** Нет нового факта, цифры, срока или обещания без источника в фактбазах. Сокращаем и переставляем — не дописываем.

## 3. Проверка

```
cd proba-site-v3 && DIST=/tmp/proba-check node scripts/build.mjs
```

Сборка должна пройти без ошибок: непомеченные цифры, запрещённые слова, битые ссылки и якоря.
