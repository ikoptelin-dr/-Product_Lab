# Промпты для следующих улучшений Proba Lab

Готовые задания для следующих сессий с Claude. Копируйте целиком. Каждый промпт опирается на файлы репозитория `-Product_Lab`, ветка `claude/pensive-tesla-1hg10j`.

---

## 1. Пилотные клиенты: оффер и скрипт

> Прочитай `proba-growth/strategy/STRATEGY-FIXES.md`, `proba-growth/pricing/site-prices.json` и демо-кейсы в `proba-growth/content/pages/kejsy/`. Подготовь программу «5 пилотных клиентов»: условия (скидка в обмен на согласие показать проект и отзыв), одностраничник для переписки, скрипт первого звонка по методу JTBD, шаблон согласия на публикацию кейса, критерии отбора клиента из главного сегмента. Без выдуманных цифр. Сохрани в `proba-growth/sales/pilot-program.md`, закоммить.

## 2. Канал контрактных производителей

> Прочитай `proba-growth/strategy/BUSINESS-OPPORTUNITIES.md` (п. 3) и `STRATEGY-FIXES.md`. Подготовь партнёрскую программу для контрактных производителей БАД и косметики: ценность для производителя, схема вознаграждения (2–3 варианта), одностраничник, письмо-приглашение, сценарий встречи, список из 20 типов производителей и где их искать (выставки, каталоги, ассоциации) — без выдуманных названий компаний. Обнови страницу `partneram` на сайте, если нужно. Закоммить.

## 3. Telegram-канал и контент-план на 8 недель

> Используй статьи из `proba-growth/content/pages/blog/` и выводы `proba-growth/semantics/WAVE4-DEMAND.md`. Составь контент-план Telegram-канала Proba Lab на 8 недель: 2 поста в неделю, рубрики (разбор заявления на этикетке, документ недели, JTBD на примере, ошибка карточки), черновики первых 6 постов, правила по стайлгайду `CONTENT-GUIDE.md` (факты только из фактбаз, без обещаний результата). Сохрани в `proba-growth/content/telegram-plan.md`.

## 4. Практикум «JTBD для брендов БАД и косметики»

> Опираясь на `blog/jobs-to-be-done.md`, `blog/cjm-karta-puti-klienta.md`, `blog/kastdev-i-glubinnye-intervyu.md`, спроектируй онлайн-практикум на 3 встречи: программа, результаты участника, рабочие тетради, шаблоны (формула работы, гайд интервью, карта пути, чек-лист заявлений для БАД), цена по рынку онлайн-практикумов (найди 5–7 сопоставимых, укажи источники), лендинг практикума в формате `proba-growth/content/pages/` (тип service). Закоммить.

## 5. Библиотека 3D-тары

> Прочитай `proba-growth/content/cases/VISUALS.md`. Составь техническое задание дизайнеру на библиотеку типовой 3D-тары в Blender: 12–15 моделей (банки, флаконы, тубы, саше, дой-паки, коробки), стандарт материалов, освещения и камер, правила наложения этикетки, структура файлов, сроки и оценка трудозатрат. Добавь продукт «3D-карточка за 48 часов» в прайс с расчётом себестоимости. Закоммить.

Учти `AUDIT-2026-10-27.md` (раздел «Отложено»). Сборка для прода: `SITE_URL=https://proba-lab.ru PROD=1`. Закоммить.

## 7. Реальные изображения на сайте

> Возьми готовые изображения из папки `proba-site-v3/assets/images/` (их положит владелец по промптам `proba-growth/content/VISUALS-SITE.md` и `cases/VISUALS.md`). Встрой: обложки кейсов, первый экран направлений, карточки хабов. WebP/AVIF, `width`/`height`, `loading="lazy"` кроме первого экрана, alt по промптам. Не выдавай сгенерированных людей за команду. Прогони проверки, закоммить.

## 8. Сверка фактов партнёром

> Сгенерируй из `proba-site-v3/REGULATORY_VERIFY.md` и разделов «НЕТ В ФАКТБАЗАХ» всех ТЗ (`proba-growth/content/briefs/`) один документ для партнёра: таблица «фраза — источник — вопрос — поле для ответа», сгруппированная по приоритету (сначала страницы с наибольшим спросом). Сохрани как `.xlsx` и `.md` в `proba-growth/content/partner-review/`. После ответов партнёра — обнови статусы в `sources.ts` и тексты.
