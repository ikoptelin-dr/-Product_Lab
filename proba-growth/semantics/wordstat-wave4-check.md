# Фразы для Вордстата: маркетинговая волна (волна 4)

**Всего:** 110 фраз. Формат — точная частота: кавычки фиксируют набор слов, `!` — форму каждого слова.

**Как снимать:**
1. По каждой фразе в точном формате снимите частоту: регион **«Россия»** и **«Новосибирская область»**. Записывайте в таблицу `фраза | Россия | Новосибирская область`, фразу копируйте как есть.
2. По фразам, помеченным ★, дополнительно выгрузите хвосты (столбец «Что искали со словом…») **без кавычек и `!`**, первые 2–3 страницы. Это даст реальные вопросы для FAQ и неожиданные формулировки.
3. Короткие латинские запросы (`jtbd`, `cjm`, `custdev`) Вордстат может не принять с `!` — тогда снимите в кавычках без `!`.

Разделы — будущие страницы волны 4. Если у раздела почти нет спроса, страницу всё равно делаем: она нужна не для поиска, а чтобы клиент, пришедший за регистрацией, увидел следующий шаг. Тогда текст пишем под конверсию, а не под SEO.
