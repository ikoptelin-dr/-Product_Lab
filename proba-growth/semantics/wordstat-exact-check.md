# Фразы для точной проверки в Вордстате

**Всего:** 106 фраз. Формат — точная частота: кавычки фиксируют набор слов, `!` — форму каждого слова.

**Как снимать:**
- По каждой фразе снимите частоту дважды: регион **«Россия»** и регион **«Новосибирская область»**.
- Хвосты не нужны — только одно число.
- Записывайте в таблицу с колонками `фраза | Россия | Новосибирская область`. Фразу копируйте как есть, вместе с кавычками и `!`.

Разделы в списке — это страницы сайта, под которые собираем фразы. Базовая частота из прошлой выгрузки — в скобках, для сравнения.
