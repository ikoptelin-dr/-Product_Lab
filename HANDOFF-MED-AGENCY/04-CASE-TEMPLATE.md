# 04. Шаблон упаковки кейса и чек-лист разрешений

Кейсы — главная причина, по которой клиника, завод или бренд поверят. Поэтому правила жёсткие: **ничего не выдумываем**.

## 1. Сначала сверка — по каждому кейсу ответить основателю

| Вопрос | Зачем |
|---|---|
| Можно ли назвать клиента? Есть ли письменное «да» (сообщение в мессенджере подойдёт)? | без разрешения — только обезличенно: «производитель БАД», «биотех-компания из Новосибирска» |
| Что именно было задачей клиента (его словами)? | кейс начинается с боли клиента, а не с наших методов |
| Какие методы применены и на каких данных (сколько интервью, сообщений, запросов, источников)? | объём работы — честная замена цифрам результата, пока их нет |
| Что клиент получил на руки (файлы, документы, сайт, боты)? | конкретика вместо «провели анализ» |
| Есть ли цифры результата и откуда они (продажи, заявки, переходы, конверсия)? Кто их может подтвердить? | без источника цифру не публикуем |
| Что можно показать (скриншоты, фрагменты отчёта), а что конфиденциально? | NDA, коммерческая тайна |
| Статус: сделано, в работе или демо? | «в работе» и «демо» помечаются явно |

## 2. Шаблон кейса для сайта

```
---
title: "<Кейс: короткая суть> — <Бренд агентства>"
description: "<Задача и результат одной фразой, без преувеличений>"
h1: "<Суть кейса>"
url: "kejsy/<slug>/"
type: "case"
updated: "<дата>"
---

<Пометка статуса, если нужно: «Проект в работе» / «Демо-проект: показываем ход работы на примере» / «Клиент назван с разрешения»>

## Клиент и задача
Кто (или обезличенно), отрасль, что болело — своими словами клиента.

## Что сделали
По шагам: метод → на каких данных (объём) → что нашли.
- Нетнография: N сообщений из M сообществ за период …
- Интервью: N разговоров …
- Вордстат: N фраз, K кластеров …
- CJM: этапы, где клиент теряется …

## Что клиент получил
Список файлов и результатов: отчёт, карта пути, позиционирование, сайт, бот…

## Результат
Только подтверждённые цифры с источником («по данным Метрики клиента», «со слов клиента, письмо от …»). Нет цифр — честно: «Результат продаж оценим через N месяцев» или раздел не выводим.

## Чему научились / что сделали бы иначе
Одна-две фразы: вызывает доверие.

**[Обсудить похожую задачу]**
```

## 3. Нельзя

- Цифры без источника. «Рост в 3 раза» без данных — нельзя.
- Отзывы, которых не было, и отзывы пациентов от имени клиники.
- Называть клиента без разрешения.
- Логотипы клиентов без разрешения.
- Выдавать проект «в работе» за сделанный.
- Медицинские обещания в кейсах про клиники и БАД.
