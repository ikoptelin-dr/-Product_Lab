# Система роста Пронтосана и Браунодина

`index.html` — самодостаточная страница (открыть в браузере, сервер не нужен):
главный вывод, причинная цепочка продажи, калькулятор сценариев, план на 90 дней,
инструменты Claude Code со стартовыми промптами, метрики и ошибки.

`page.html` — та же страница без обёртки `<html>/<head>` (исходник для публикации).

`routes.html` — аптеки по районам (кого довести до 3–5 уп/мес) и ЛПУ района с порядком захода к врачам.
Выгрузка в репозиторий не кладётся: откройте страницу и перетащите CSV дистрибьютора — файл читается только в браузере.
