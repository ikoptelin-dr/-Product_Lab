# Proba Lab — сайт v3 (прототип)

Многостраничный статический сайт по `proba-growth/strategy/site-v3-vision.md`. Отдельный проект: `proba-site-v2/` не меняется.
Тексты новых страниц — дословно из видения (§4), блоки v6 и раздел «Документы» — из v2 без изменения текстов и фактов.

## Сборка и проверка

```bash
node scripts/build.mjs                       # → dist/ + REGULATORY_VERIFY.md
SITE_URL=https://домен node scripts/build.mjs # то же с настоящим адресом в sitemap.xml/robots.txt
scripts/verify.sh [папка-для-скриншотов]     # Playwright: все страницы × 1440/768/390, ссылки, квиз, формы, меню, reduced-motion
```

esbuild и Playwright берутся из `proba-site/node_modules` (своего `package.json` нет). Сборка останавливается при: непомеченной цифре или номере НПА в разделе «Документы», запрещённых словах (видение §3 + стоп-лист v2), остатках `{{`, не одном `h1`, повторе `title`, сетевых вызовах или хранилище в `site.js`.

## Дизайн-токены (`src/site.css`, `:root`)
| Токен | Значение | Где |
|---|---|---|
| `--black` | #000 | hero, шапка, подвал |
| `--bg-light` | #F4F4F5 | светлая часть («лист» со скруглением 28px поверх чёрного) |
| `--z50…--z950` | шкала zinc | текст (`--z900`), вторичный текст (`--z600`, ≥ 7:1), линии |
| `--emerald` | #34D399 | акцент на тёмном; кнопка с текстом `--on-emerald` #022C22 (10.6:1) |
| `--emerald-ink` | #047857 | ссылки, номера, фокус на светлом (5.0:1 на #F4F4F5) |
| `--glass-border` | rgba(255,255,255,.1) | `.glass`: blur 20px, фон 5.5% белого (на мобильных blur 12px) |
| `.glass-light` | белый 72% + blur 20px, граница zinc 9% | карточки на светлом; без `backdrop-filter` — непрозрачный фон |
| `--ease` | cubic-bezier(.2,.8,.2,1) | всё движение; `prefers-reduced-motion` отключает анимации и переходы |
| Шрифт | Inter 400/500/600/700 (Google Fonts) | H1/H2 −0.04…−0.048em, H3 и текст 0…−0.01em |

Кнопки на светлом — монохромные (zinc-900), изумрудная кнопка — только на тёмном. Зерно — SVG-шум 7% только на тёмных блоках. Кнопки действия не анимируются; появление блоков — только ниже первого экрана, без JS всё видно.
