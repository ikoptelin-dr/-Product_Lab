# Proba Lab — сайт v3 (прототип)

Многостраничный статический сайт по `proba-growth/strategy/site-v3-vision.md`. Отдельный проект: `proba-site-v2/` не меняется.
Тексты новых страниц — дословно из видения (§4), блоки v6 и раздел «Документы» — из v2 без изменения текстов и фактов.

## Сборка и проверка

```bash
node scripts/build.mjs                       # → dist/ + REGULATORY_VERIFY.md
SITE_URL=https://домен node scripts/build.mjs # то же с настоящим адресом в sitemap.xml/robots.txt
scripts/verify.sh [папка-для-скриншотов]     # Playwright: все страницы × 1440/768/390, ссылки, sitemap, JSON-LD, квиз, формы и согласие, калькулятор, меню, reduced-motion
```

esbuild и Playwright берутся из `proba-site/node_modules` (своего `package.json` нет). Сборка запускает `/usr/bin/pandoc` (юридические документы, см. ниже). Сборка останавливается при: непомеченной цифре или номере НПА в разделе «Документы», в статьях блога, регуляторных новостях и на «Карте документов», запрещённых словах (видение §3 + стоп-лист v2), остатках `{{`, не одном `h1`, повторе `title`, сетевых вызовах или хранилище в `site.js`.

## Страницы подвала, цены, лид-магниты, блог (v3, октябрь 2026)
- **Тексты** — дословно из `content/footer-pages.md`. Заметки «>» и «[решение владельца]» на сайт не выводятся — собраны ниже.
- **COMPANY** (`src/data.ts`): ИП, ИНН, ОГРНИП, дата регистрации, адрес, телефон (`tel:+79994662279`), почта, банк. Используется в подвале (строка реквизитов, телефон, почта), на «Контактах» (реквизиты полностью), «Оплате» (платёжные реквизиты), в JSON-LD `Organization` на главной (legalName, taxID, address, telephone, email) и `LocalBusiness` на «Контактах» (без часов работы).
- **Подвал**: прежние группы + «Компания» (О нас, Контакты, Партнёрам, Благотворительность, Новости, Блог) и «Клиентам» (Цены, Оплата, Публичная оферта, Политика обработки ПДн, Правовая информация); в «О работе» добавлены «Калькулятор SKU» и «Карта документов» (иначе на лид-магниты нет постоянной ссылки). Строка «ИП Коптелин Илья Алексеевич · ИНН … · ОГРНИП …», телефон и почта.
- **Шапка**: «Цены» добавлены седьмым пунктом (при 1440 меню в одну строку, verify проверяет) и в мобильное меню.
- **Согласие** на всех формах (`consent(base)` в `forms.ts`, форма раздела в `regulatory/render.ts`): «Согласен на обработку персональных данных», ссылка на `soglasie-pd.html` в той же вкладке.
- **Цены** (`ceny.html`): все 40 позиций `site-prices.json` по блокам, «от X ₽» + единица + что входит; 0 → «Бесплатно»; у единицы «фикс» цена без «от» и подпись «фиксированная цена». Под блоком «Документы» — смета строками без сумм. JSON-LD `OfferCatalog` → `Offer` (price = from, priceCurrency RUB, description «от …» / «Бесплатно») — только на этой странице.
- **Строки «Цены»** на направлениях: минимальная цена блока с тем же названием (Маркетинг, Продвижение, Аналитика, Аудит продаж, Автоматизация) + «Все цены». В «Документах» — только однозначные соответствия (`DOC_PRICE_MAP`): registraciya-bad, kosmetika (декларация и СГР), deklaracii, tu, markirovka (проверка этикетки), haccp; остальные страницы раздела — только ссылка на `ceny.html#dokumenty`. Эти строки помечены `proba-price` и попадают в `REGULATORY_VERIFY.md`.
- **Калькулятор** (`kalkulyator-sku.html`, `src/calc.ts`): 9 полей, запятая как разделитель, пересчёт при вводе, ошибки у поля (`aria-invalid`), итог в `aria-live`, без отправки и хранилища. Прибыль = цена − себестоимость − цена×комиссия − логистика − доля возвратов×обратная логистика − реклама − цена×налог − упаковка; безубыточность = расходы в ₽ / (1 − комиссия − налог). Форма «Обсудить задачу» с предвыбором «Аналитика».
- **Карта документов** (`dokumenty/karta-dokumentov.html`): что получите, пример на условном «Магний B6, таблетки» с меткой «Пример», форма (продукт, состав текстом или файлом, производство, каналы, «Что нужно» = «Определить, какой документ нужен», контакт, согласие). Файл не загружается — прототип.
- **Блог**: статьи написаны по `regulatory-docs-factbase.md` (повторно использованы ключи `sources.ts`); каждая фраза с цифрой, датой или НПА помечена `f(ключ, фраза)` — сборка падает на непомеченной. В `REGULATORY_VERIFY.md` у статей отметка «Проверено специалистом-партнёром: ожидает сверки» (на сайте не показывается). Статья об экономике SKU фактов с цифрами не содержит, ставок площадок нет.
- **Новости**: регуляторные пункты 2–3 помечены на сайте «Проверяется» и выписаны в `REGULATORY_VERIFY.md`.
- **Юридические документы** — источник `/home/user/-Product_Lab/proba-legal/*.md` (oferta, politika-pd, soglasie-pd, pravovaya-informaciya; `rekvizity.md` не публикуется). `scripts/build.mjs` переводит их `pandoc -f gfm-smart+hard_line_breaks` (текст без изменений, без «умных» кавычек, переносы строк в реквизитах сохраняются); первый `# …` — h1, якоря разделов `#p1…#p13`. Правка текста — только в `proba-legal`, затем пересборка.

## Ждёт решения владельца
1. **Почта — расхождение.** В юридических документах (оферта п. 1.4, согласие, правовая информация, реквизиты) — `I.koptelin@yandex.ru`; в `content/footer-pages.md` — `ikoptelin@yandex.ru`. На сайте везде `COMPANY.email = "I.koptelin@yandex.ru"`. Подтвердите адрес; если верен другой — поменять в `src/data.ts` и в `proba-legal/*.md`.
2. **Оплата для физических лиц** — подключить онлайн-кассу или работать только с ИП и компаниями (на `oplata.html` сейчас: «Для физических лиц — по счёту после подключения онлайн-кассы»).
3. **Благотворительность** — подтвердить сам факт программы, формат и лимит («до одного проекта в месяц»). Фонды, суммы и «помогли N проектам» не указываются, пока нет реальных фактов.
4. **О нас** — ссылка на профиль eLibrary/ORCID (добавить, когда пришлёте). Работодатель основателя и его клиенты не упоминаются, число публикаций не указано.
5. **Контакты** — часы работы не указаны (и нет в JSON-LD), пока не утверждены.
6. **Новости, п. 4** — текст «Зарегистрировано ИП Коптелин И. А. … юридическое лицо, через которое работает Proba Lab» оставлен дословно, но ИП юридическим лицом не является; предлагаем «— форма, через которую работает Proba Lab».
7. **Цены** — в `site-prices.json` нет поля `publish`, опубликованы все 40 позиций. Статусы: «партнёр подтверждает» (все платные позиции «Документов»), «рекомендация», «гипотеза — проверить спрос» (Экономика SKU), «утверждено на сайте; расшифровать «материал»» (Сопровождение). Решите, что снять до публикации.
8. **Title «Партнёрам…»** из footer-pages.md — 72 символа; лимит в `layout.ts` поднят с 70 до 75, чтобы оставить его дословно.
9. **Цена «фикс»** («Предложение для одного продукта», «Разбор одного процесса») показана без «от» с подписью «фиксированная цена»; в JSON-LD description — «от …», как требует задание.
