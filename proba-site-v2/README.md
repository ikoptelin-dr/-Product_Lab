# Proba Lab — лендинг (v5)

Путь страницы: узнаваемая проблема → бесплатный разбор продукта → первый заказ «Предложение для одного продукта» → конструктор проекта → расчёт.

- `src/data.ts` — **единственное место** для цен (`PRICES`), услуг конструктора, пакетов, адреса приёма заявок (`LEAD_ENDPOINT`) и отзывов (`REVIEWS`).
- `src/body.html` — разметка и тексты. Карточки конструктора, цены и отзывы подставляются при сборке из `data.ts`.
- `src/styles.css` — стили: Manrope (заголовки) + Golos Text (текст), петроль #0B5C66 и янтарь #B9761C, светлая и тёмная темы.
- `src/app.ts` — меню, вкладки, конструктор (выбор хранится в localStorage, контакты не сохраняются), формы, движение.
- `scripts/build.mjs` → `dist/proba-lab.html` (самодостаточный файл).

```bash
node scripts/build.mjs
```

## Что нужно подключить перед публикацией
1. **Приём заявок.** Укажите `LEAD_ENDPOINT` в `src/data.ts` — адрес, принимающий POST JSON `{ kind: "review" | "calc", productUrl, contact, task, term, project[] }`. Подойдёт API из `../proba-site` (`app/api/lead`) после адаптации полей, вебхук CRM или сервис форм. Пока адрес пуст, форма честно пишет, что заявка не отправлена.
2. **Отзывы.** Добавляйте только настоящие согласованные отзывы в `REVIEWS` — секция «Что говорят клиенты» появится автоматически.
3. **Реквизиты, политика обработки персональных данных и контакты** — на сайте сейчас не публикуются; их нужно добавить в подвал и отдельные страницы перед запуском.
4. Имя и фото основателя — по желанию; сейчас блок команды оформлен без фиктивной личности.
